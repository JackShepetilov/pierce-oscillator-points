# Точки серии «помеха → генератор Пирса 11 МГц» в явном виде

Здесь лежат отдельные точки серии от 10.11.2026, выгруженные **в явном виде**:
- сырые осциллограммы в CSV;
- каждый шаг обработки, отдельно для каждого из 200 импульсов;
- итоговые числа;
- графики.

Всё это открывается в MATLAB, Excel или любом редакторе, Python для чтения не нужен.

Сейчас выгружена одна точка: **прямоугольник, 10 В, 100 нс** → папка [`rect_A10V_W100ns/`](rect_A10V_W100ns/).

Ниже по шагам написано, как сделать такую же папку для **любой другой точки** серии.
Все пути в инструкции — относительно папки этого репозитория. Работает на Windows, macOS и Linux.

---

## 1. Что лежит в репозитории

```
<папка репозитория>/
├── README.md                    ← этот файл
├── export_point.py              ← программа, которая делает папку точки
├── .gitignore
└── rect_A10V_W100ns/            ← одна точка = одна папка
    ├── 00_README.txt            что в каждом файле и как он посчитан
    ├── 01_raw_CH1_pulse_V.csv   сырая помеха (CH1), 200 импульсов
    ├── 02_raw_CH2_osc_V.csv     сырая генерация (CH2), 200 импульсов, уже ÷10
    ├── 03_frequency.csv         частота каждого импульса
    ├── 04_phantom.csv           «фантом» (синусоида до помехи) каждого импульса
    ├── 05_track_dphi_deg_each.csv   сдвиг фазы в бегущем окне, каждый импульс
    ├── 06_track_amp_rel_each.csv    амплитуда в бегущем окне, каждый импульс
    ├── 07_track_mean.csv        среднее по импульсам
    ├── 08_per_event_result.csv  итог по каждому импульсу
    ├── 09_result.txt            итоговые числа точки
    └── fig1 … fig5 .png         графики
```

Каждая новая точка ложится рядом отдельной папкой, например `gauss_A5V_W200ns/`.

## 2. Что нужно, чтобы сделать новую точку

### 2.1. Python

**Python 3** с пакетами `numpy` и `matplotlib`:
```bash
pip install numpy matplotlib
```
На macOS/Linux команда может называться `python3` и `pip3` — тогда пишите так и дальше.

### 2.2. Сырые данные серии — их в репозитории НЕТ

Сырые данные лежат в файлах `.npz`: один файл на точку, ~33 МБ, вся серия ~17 ГБ.
В репозиторий они не входят, их надо **получить отдельно** у автора эксперимента.
Подходит любой из двух вариантов.

**Вариант А — вся серия.** Это папка `sweep_20261110_144320`, внутри неё подпапки по формам:
```
sweep_20261110_144320/
├── rect/        A10V_W100ns_raw.npz, A5V_W200ns_raw.npz, … и summary.csv
├── haversine/
├── triangle/
├── gauss/
└── sinecycle/
```
Проще всего положить эту папку **прямо в папку репозитория** (рядом с `export_point.py`) или
на уровень выше. Тогда программа найдёт её сама.
Если она лежит в другом месте, путь к ней передаётся ключом `--sweep` (шаг 2 ниже).

**Вариант Б — только нужные точки.** Достаточно одного файла, например `gauss/A5V_W200ns_raw.npz`.
Положить куда угодно и передать программе путь к файлу (раздел 5).

### 2.3. Место на диске

Около **160 МБ** на одну выгруженную точку, почти всё — два сырых CSV.

## 3. Какие точки есть в серии

| Форма | Имя в команде | Амплитуды A, В | Ширины W, нс | Точек |
|---|---|---|---|---|
| прямоугольник | `rect` | 2, 3, 5, 7, 10 | 10, 15, 20, 25, 30, 35, 40, 45, 50, 60, 70, 80, 90, 100, 120, 135, 150, 180, 200, 250, 300, 400, 500 | 115 |
| «горбик» 1 − cos | `haversine` | то же | то же | 115 |
| гауссиана | `gauss` | то же | то же | 115 |
| один период синуса | `sinecycle` | то же | то же | 115 |
| треугольник | `triangle` | то же | **только** 100, 120, 135, 150, 180, 200, 250, 300, 400, 500 | 50 |

- **A** — пик положительного лепестка, который заказали генератору.
- **W** — ширина этого лепестка на полувысоте, тоже заказ.

Имя файла точки: `A<A>V_W<W>ns_raw.npz`, например `A5V_W200ns_raw.npz`.
Реально измеренные пик, ширина и площадь помехи лежат в `summary.csv` в папке каждой формы.

## 4. Как сделать новую точку — по шагам

Пример: гауссиана, 5 В, 200 нс.

**Шаг 1. Открыть терминал в папке репозитория.**
- Windows: открыть папку репозитория в Проводнике, в адресной строке написать `powershell` и нажать Enter.
- macOS/Linux: открыть терминал и перейти в папку командой `cd <путь к папке репозитория>`.

**Шаг 2. Запустить программу.** После имени файла идут три значения: форма, амплитуда в вольтах, ширина в наносекундах.

Если папка `sweep_20261110_144320` лежит в репозитории или на уровень выше:
```bash
python export_point.py gauss 5 200
```
Если она лежит где-то ещё, путь к ней надо указать:
```bash
python export_point.py gauss 5 200 --sweep "<путь к sweep_20261110_144320>"
```
Например: `--sweep "D:\data\sweep_20261110_144320"` или `--sweep ~/data/sweep_20261110_144320`.

**Шаг 3. Подождать около 15 секунд.** Программа напечатает итог, например:
```
gauss_A5V_W200ns: 200 событий × 39999 точек, шаг 0.40 нс  ->  .../gauss_A5V_W200ns
  пишу 01_raw_CH1_pulse_V.csv ...
  пишу 02_raw_CH2_osc_V.csv ...
  частота f0 (медиана), Гц: ...
  макс. среднее отклонение фазы (где амплитуда > 0,5), °: ...
  ...
Готово.
```
В репозитории появится папка `gauss_A5V_W200ns/` с тем же набором файлов, что у `rect_A10V_W100ns/`.

**Шаг 4. Проверить.** Сравнить числа из `09_result.txt` со строкой этой точки в
`sweep_20261110_144320/gauss/summary.csv` (раздел 6). Должны совпасть.
Если `summary.csv` нет (вариант Б), этот шаг можно пропустить.

**Шаг 5. Сохранить в git:**
```bash
git add gauss_A5V_W200ns
```
```bash
git commit -m "Точка gauss 5 В 200 нс"
```
Папку серии внутри репозитория git не замечает (она записана в `.gitignore`), так что 17 ГБ в git случайно не попадут.

Готово. Для следующей точки — снова с шага 2.

### Несколько точек подряд

Windows (PowerShell), например все ширины прямоугольника при 5 В:
```powershell
foreach ($w in 10,20,50,100,200,500) { python export_point.py rect 5 $w }
```
macOS/Linux:
```bash
for w in 10 20 50 100 200 500; do python3 export_point.py rect 5 $w; done
```
Каждая точка — ~160 МБ и ~15 с: 6 точек — ~1 ГБ и ~1,5 мин.
Если серия не рядом с программой, допишите в команду `--sweep "<путь>"`.

### Если что-то не так

| Сообщение | Что делать |
|---|---|
| `Не нашёл папку серии sweep_20261110_144320` | указать путь ключом `--sweep` или положить папку рядом с `export_point.py` |
| `Нет файла: …` и список `В … есть: …` | такой точки нет; выбрать из списка. Частая причина — треугольник с W < 100 нс или ширина не из таблицы раздела 3 |
| `Проверьте форму …` | опечатка в имени формы: `rect`, `haversine`, `triangle`, `gauss`, `sinecycle` |
| `No module named numpy` (или matplotlib) | `pip install numpy matplotlib` |
| `python` не найден | на macOS/Linux писать `python3`; на Windows установить Python с python.org и при установке поставить галочку «Add to PATH» |

## 5. Другие способы запуска

| Что нужно | Команда |
|---|---|
| указать файл точки прямо (вариант Б) | `python export_point.py "<путь>/A5V_W200ns_raw.npz"` |
| серия лежит в другом месте | `python export_point.py gauss 5 200 --sweep "<путь к sweep_20261110_144320>"` |
| писать в другую папку | `python export_point.py gauss 5 200 --out "<папка вывода>"` |
| справка | `python export_point.py -h` |

Повторный запуск для той же точки **перезаписывает** её папку. Файлы `*_raw.npz` программа **не меняет никогда**.

### Параметры обработки

Они в начале `export_point.py`:

| Параметр | Сейчас | Что это |
|---|---|---|
| `WIN` | 0,3 мкс | длина бегущего окна подгонки |
| `STEP` | 0,1 мкс | шаг окна |
| `REC_PHASE`, `REC_AMP` | 2°, 5 % | порог «восстановилось» |
| `CH2_FIX` | 10 | на сколько делить CH2 (ошибка настройки щупа) |

Если параметры поменять, числа перестанут совпадать с `summary.csv`. Это нормально, но запишите это в сообщении коммита.

`summary.csv` лежит в папке каждой формы (`sweep_20261110_144320/<форма>/summary.csv`), одна строка на точку.

| В `09_result.txt` | Столбец в `summary.csv` | Замечание |
|---|---|---|
| частота f0 | `f_hz` | |
| равномерность фазы попадания R | `R_phase` | |
| макс. среднее отклонение фазы, при t | `dev_max`, `dev_max_t_us` | в `summary.csv` максимум ищется и там, где генерация почти заглохла. Поэтому при больших A и W там бывает больше (пример: 57° против 44° у rect 10 В / 300 нс). Здесь только где амплитуда > 0,5 — как в отчётах |
| мин. средняя амплитуда | `amp_min` | |
| время восстановления | `t_rec_us` | |
| постоянный сдвиг (среднее) | `shift_mean` | |
| разброс между событиями | `shift_std` | |
| зависимость от фазы попадания (PRC) ±, макс. при | `prc_amp`, `prc_phase` | |
| амплитуда генерации до помехи | `amp_before` | в `summary.csv` **в 10 раз больше** (там CH2 не поделён) |

## 7. Что надо знать о данных

- **CH2 (генерация) в CSV уже поделён на 10.** Щуп стоял 1:1, а в настройке канала было 10:1.
  В исходных `*_raw.npz` и в `summary.csv` вольты CH2 в 10 раз больше. На фазы и относительную
  амплитуду это не влияет.
- **CH1 (помеха) при A ≥ 7 В обрезан сверху на ~6,4 В** — это край экрана осциллографа. На поиск фронта не влияет.
- **В трёх слабых точках часть импульсов не обрабатывается:** rect 2 В/10 нс (1 импульс), gauss 2 В/10 нс (2),
  haversine 2 В/15 нс (1). Там помеха в этих импульсах не дотянула до уровня поиска фронта.
  Программа пишет их номера на экран и в `09_result.txt`. В сырых CSV они есть, в файлах 04–08 их нет.
  Так же сделано в основной обработке серии, поэтому числа совпадают с `summary.csv`.
- **Время 0** — момент запуска осциллографа по фронту помехи. Запись от −8 до +8 мкс, шаг 0,4 нс.
- **Фаза там, где генерация почти пропала, не показана.** На графиках там, где A/A0 < 0,5, фаза пропущена:
  синусоиды почти нет, и фаза получается случайной. В CSV эти числа есть, но верить им нельзя.
- **Фаза попадания** — где была синусоида генерации в момент фронта помехи (0…360°).
  Генератор помехи и схема не синхронны, поэтому фазы попадания покрывают весь круг.
- **Постоянный сдвиг фазы** (через 4…8 мкс после помехи) в этой серии около нуля.
  Сама подгонка даёт ложную «зависимость от фазы попадания» порядка ±0,01…0,14°,
  поэтому `PRC` такого размера — не эффект.

## 8. Открыть в MATLAB

Текущая папка MATLAB — папка репозитория.
```matlab
M = readmatrix('rect_A10V_W100ns/02_raw_CH2_osc_V.csv');   % 39999 × 201
t = M(:,1);            % время, мкс
x = M(:,2:end);        % 200 импульсов, по столбцу на импульс, В
plot(t, x(:,1)); xlim([-1 3])

R = readtable('rect_A10V_W100ns/08_per_event_result.csv');
plot(R.phase_hit_deg, R{:,3}, '.')     % пик Δφ против фазы попадания
```
Разделитель — запятая, десятичная точка — точка, первая строка — заголовки.

В Excel: «Данные → Из текста/CSV», разделитель «запятая». Сырые CSV (~80 МБ, 40 000 строк × 201 столбец)
Excel открывает медленно. Для них лучше MATLAB.

## 9. Про размер репозитория

Каждая точка добавляет ~160 МБ. Сам git на компьютере с этим справляется.

Если загружать репозиторий на GitHub: там предупреждение на файлы > 50 МБ и запрет на файлы > 100 МБ.
Сырые CSV одной точки — 77–81 МБ, то есть пройдут, но с предупреждением.
Для большого числа точек лучше Git LFS или не класть сырые CSV в git: их всегда можно
сделать заново командой из раздела 4.
